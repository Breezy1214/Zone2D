Zone2D

A zone defined by a part's horizontal footprint. Tracked models fire Entered and Exited as their PrimaryPart moves in and out of the footprint, with an optional height cap and an above-only mode. 

local zone = Zone2D.new(workspace.ShopFloor, { MaxHeight = 20 })
zone:TrackPlayers()

zone.Entered:Connect(function(character)
	print(character.Name, "entered")
end)

interface ZoneOptions {
MaxHeight: number?--

Maximum distance from the part's centre along its up axis.

AboveOnly: boolean?--

Only count points on or above the part's centre plane.

}

Properties​

Entered​

</>
Zone2D.Entered: Signal<Model>

Fires when a tracked model's PrimaryPart enters the zone.

Exited​

</>
Zone2D.Exited: Signal<Model>

Fires when a tracked model leaves the zone, is untracked while inside, or leaves the workspace.

TrackModel​

</>
Zone2D:TrackModel(model: Model) → ()

Tracks a model to detect when it enters/exits the zone. The model must be parented to workspace. Detection begins once it has a PrimaryPart.

UntrackModel​

</>
Zone2D:UntrackModel(model: Model) → ()

Stops tracking a model. If the model was inside the zone, it will fire the Exited event.

</>
Zone2D:TrackPlayers() → ()

Convenience function to track all player characters. Automatically tracks new players and characters as they are added.

</>
